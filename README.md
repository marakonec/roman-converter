# Конвертер римських чисел

Консольна програма для перетворення чисел у римський запис і навпаки.

Це **еталонний проєкт** курсу "Професійна практика програмної інженерії" (Український державний університет науки і технологій, кафедра комп'ютерних інформаційних технологій). 
Він показує, як виглядає невелика програма, доведена до стану опублікованого продукту.

## Що робить програма

- перетворює ціле число від 1 до 3999 у римський запис: `1994` → `MCMXCIV`;
- перетворює римський запис у число: `MCMXCIV` → `1994`;
- перевіряє коректність запису: `IIII` і `ABC` відхиляються;
- має вбудований режим самоперевірки на восьми контрольних прикладах.

## Як зібрати

Потрібна Visual Studio 2026 із робочим навантаженням "Розробка класичних програм на C++".

1. Відкрити `roman-converter.slnx`.
2. Обрати конфігурацію `Release` і платформу `x64`.
3. `Збірка → Зібрати рішення` (`Ctrl+Shift+B`).

Готовий файл з'явиться в `x64\Release\roman-converter.exe`.

## Як запустити без збірки

Завантажте архів зі сторінки [Releases](../../releases), розпакуйте й запустіть `roman-converter.exe`. Visual Studio для цього не потрібна.

## Приклад роботи

```
 Конвертер римських чисел 
1 - число -> римський запис
2 - римський запис -> число
3 - самоперевірка
0 - вихід
Ваш вибір: 1
Введіть число: 2026
2026 = MMXXVI
```
